⚙ Operations & Input Guide

Add / Subtract / Multiply

Enter both A(x) and B(x) in standard form (e.g. 4x^3 - 2x + 7).
These operations combine or modify polynomial coefficients directly.

Divide

Provides Quotient and Remainder when dividing A(x) by B(x).
Example: (x³ - 2x + 4) ÷ (x - 1).

Derivative

Select Derivative of A or B to compute d/dx of the selected polynomial.
Example: d/dx(3x² + 4x) = 6x + 4.

Integral

Computes the Indefinite Integral of A(x) or B(x).
Example: ∫(2x + 3) dx = x² + 3x + C.

Evaluate

Choose Evaluate A or B, then provide a numeric value for x.
Example: A(x) = 2x² + 3x + 1 → A(2) = 15.

Note: Use x for variable and ^ for exponents (e.g. 4x^3 - 2x + 7).

This interface is connected to a Python backend to process calculations dynamically.
